# Alekas Packages

Este repositório contém os scripts, configurações e patches de compilação de pacotes para o ecossistema **Alekas** no Android.

## Agradecimentos e Licenciamento

O **Alekas** é construído com respeito e gratidão a toda a comunidade de **Software Livre (GNU)** e aos projetos de código aberto que tornam este ecossistema possível, incluindo os componentes originais de emulação de terminal e empacotamento.

Todas as marcas registradas, logotipos e direitos de terceiros pertencem aos seus respectivos proprietários e são citados em conformidade com as suas licenças de código aberto.

## Estrutura do Projeto

* `packages/`: Definições dos pacotes principais
* `root-packages/`: Pacotes que requerem acesso root
* `x11-packages/`: Pacotes e bibliotecas para ambiente gráfico X11
* `build-package.sh`: Script principal de compilação de pacotes
