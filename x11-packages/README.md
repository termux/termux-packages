# GameTurboStudio

Android Studio project for a safe, non-root gaming dashboard.

## Features
- Gaming Mode UI toggle
- Live RAM usage
- Battery percentage
- Storage usage
- Android 13 / RMX3195 compatible baseline
- Jetpack Compose UI
- No root required

## Open
Open this folder in Android Studio and let Gradle sync.

## Build
Android Studio: Build > Build APK(s)

Or terminal:
./gradlew assembleDebug

The APK will be under:
app/build/outputs/apk/debug/
